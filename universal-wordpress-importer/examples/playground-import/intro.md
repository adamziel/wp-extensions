# Field Notes Import Demo

This Markdown page is part of the sample content bundled with Universal
WordPress Importer.

It includes content that should become native WordPress blocks:

- A heading
- Paragraphs
- A list
- A local link to [Chapter Two](chapter-two.md)
- An external image reference

![WordPress logo](https://s.w.org/style/images/about/WordPress-logotype-wmark.png)

The external image URL is intentionally left outside the source domain so you
can see how the importer preserves non-first-party URLs.
