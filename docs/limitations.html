Static exports are snapshots, not backend services.

PortPress is strongest when the public site can be represented as rendered HTML, CSS, JavaScript, media, and rewritten links. Anything that writes to WordPress still needs a backend or a static-friendly replacement.

Preview behavior

Direct file:// previews are convenient, but browsers block JavaScript ES modules from file:// origins. WordPress Interactivity API modules and similar frontend modules need at least a local HTTP server.

python3 -m http.server 8080

WooCommerce snapshots

WooCommerce pages export as rendered HTML snapshots. Product listings, product pages, images, and static cart page markup can work well. Live cart mutations, checkout processing, account pages, order actions, and payment flows still need a WordPress backend or a dedicated static-compatible service.

Best fit

PortPress static exports are best for content sites, docs, portfolios, brochure sites, static product catalogs, and exports you want to inspect or host on simple static infrastructure such as GitHub Pages.
