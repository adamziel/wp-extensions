Limitations

StillPress exports the rendered public site. It does not turn dynamic WordPress features into static services.

file:// Preview Limits

Direct file previews are convenient, but browsers block JavaScript ES modules from file:// origins. WordPress Interactivity API modules and similar frontend modules need at least a local HTTP server.

python3 -m http.server 8080

WooCommerce Snapshots

WooCommerce pages export as rendered HTML snapshots. Product listings, product pages, images, and static cart page markup can work well. Live cart mutations, checkout processing, account pages, order actions, and payment flows still need a WordPress backend or a dedicated static-compatible service.

Forms, Search, Comments, and REST

Contact forms, search requests, comment submission, admin actions, nonce-protected endpoints, and REST API writes are dynamic. Keep them out of a purely static build or replace them with services designed for static hosting.

Best Fit

StillPress is best for content sites, docs, portfolios, brochure sites, static product catalogs, and exports you want to inspect or host on simple static infrastructure.
