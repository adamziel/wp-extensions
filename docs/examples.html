Examples

Use these examples to verify that exported pages are distinct, links are rewritten, and assets are copied.

Content Site Demo

The browser demo seeds pages, categories, dated posts, and block content. It opens directly to the StillPress admin screen.

Open static-site-generator-browser.json in Playground

BrewCommerce Demo

The BrewCommerce Blueprint imports a richer coffee shop site with WooCommerce, product images, product pages, a shop page, cart snapshot, and theme/plugin CSS.

Open static-site-generator-brewcommerce.json in Playground

  • Export the ZIP from Tools -> StillPress.
  • Extract it and run python3 -m http.server 8080.
  • Check /, /shop/, /cart/, and at least one /product/... page.
  • Confirm product images render, product grids stay tiled, and links point to exported files.

CLI Export Blueprint

The CLI Blueprint runs the export command in Playground and writes the ZIP to a mounted output folder.

View static-site-generator-cli-export.json
