Static export examples

Use these PortPress demos to verify the exported site, not just the export command. A good export has distinct pages, rewritten links, copied assets, and sensible behavior over local HTTP.

Content site demo

Open the seeded demo

The browser demo creates pages, categories, dated posts, and block content. It opens directly to the current static export admin screen.

Verify the ZIP

  • Export the ZIP from Tools -> StillPress.
  • Extract it and run python3 -m http.server 8080.
  • Open several internal links and confirm they stay inside the export.

BrewCommerce demo

The BrewCommerce Blueprint imports a richer coffee shop site with WooCommerce, product images, product pages, a shop page, cart snapshot, and theme/plugin CSS.

  • Check /, /shop/, /cart/, and at least one /product/... page.
  • Confirm product images render and product grids stay tiled.
  • Treat checkout, account actions, and live cart mutation as dynamic WooCommerce behavior that still needs a backend.

CLI export Blueprint

The CLI Blueprint runs the export command in Playground and writes the ZIP to a mounted output folder.

View static-site-generator-cli-export.json

mkdir -p ./static-site-output
npx @wp-playground/cli@latest run-blueprint \
	--mount=./static-site-generator:/wordpress/wp-content/plugins/static-site-generator \
	--mount=./static-site-output:/exports \
	--blueprint=./blueprints/static-site-generator-cli-export.json
