Introduction

The block editor (Gutenberg) is the modern editing experience in WordPress. All headings and ordered TOC entries are extracted automatically — they will become the parent slugs in your handbook. The first paragraph of each page is used as the meta description unless a frontmatter field overrides it.

Inside this document you will find references to images stored under /docs/assets/, which the importer rewrites to your media library URL. External anchors to MDN and other docs sites keep their fragments; internal anchors are remapped to the new slugs.

Getting started

You can install Gutenberg from the plugin directory or download a release. The legacy editor remains available via the Classic Editor plugin. Note: this paragraph is rewritten to remove obsolete advice — see comment on the right. Once installed, every new post uses blocks by default.

Authors referenced as @gziolo, @youknowriad, @ellatrix are mapped to existing WP users. If a contributor cannot be matched, the page is attributed to the importer's owner.

Theme.json

The theme.json file is a configuration mechanism for global styles. Read about block supports, style variations, and layout. Links are inspected before publish.

Patterns

Block patterns are predefined arrangements of blocks. The importer detects pattern files at docs/patterns/*.html and registers them as theme patterns rather than pages.
