A note on Base URLs

Why we ask for more than just a domain.

Older importers asked only for a domain — example.com. That worked when every site lived at its root. Today, your content might live under a subpath, behind a CDN, or be mirrored across schemes.

The new Base URL is the full scheme + domain + path of where the content was originally served. We rewrite every internal link relative to it.

scheme httpsdomain example.compath /docs/

https://example.com/docs/

Drop the /docs/ and a link to /docs/guide would become an external URL after import. Keep it, and the importer knows that page now lives inside your WordPress.

How should we write?

Choose a write mode — you can switch on the next run.
Publish pagesUpdate matching slugs, keep the rest. Recommended for re-imports.
FreshCreate new posts. Existing content untouched.
MirrorMake WP match source exactly. Deletes orphans. Destructive.
Dry runWalk the source, report a plan, write nothing.
