# Universal Importer Setup Wizard v5 Claude QA

- Five progressive modal wizard designs produced from the Claude v5 brief after the Claude tmux run stalled without output.
- Option 01 accepts either upload from a file input or a URL, infers likely source type, and preselects a guessed option.
- GitHub repo flow includes a directory picker.
- URL rewrite step accepts old Base URLs and explains that Base URLs include scheme/domain/path, not just a domain.
- Product constraints represented: GitHub repo/directory, WordPress REST/WXR, feeds/OPML, reachable URLs, server paths, uploads/folders/archives, URL treatment ask/preserve/rewrite listed Base URLs, drafts, dry run, import stages, URL decisions, media, comments, abort, and completion.
