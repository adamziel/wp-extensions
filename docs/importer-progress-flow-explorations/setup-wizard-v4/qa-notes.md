# Universal Importer Setup Wizard v4 QA

- Updated after feedback that the varied pass still showed too much information at once.
- Contains 20 progressive wizard variations where only the immediately relevant step is visible by default.
- Hidden/revealed steps preserve real importer support: GitHub repo/directory, WordPress REST/WXR, feeds/OPML, reachable URLs, server paths, uploads/folders/archives, URL treatment ask/preserve/rewrite, old domains, drafts, dry run, import stages, URL decisions, media, comments, abort, and completion.
- Unsupported connector claims such as Shopify, Notion, Drive, Slack, account auth, arbitrary DB tables, and custom post type imports are intentionally excluded.
