# Universal Importer Setup Wizard v4 QA

- Updated after review feedback that the first v4 pass was too repetitive.
- Contains 20 standalone, interactive setup-wizard variations with different layout models: cards, WP admin, explorer, accordion, terminal, GitHub tree, upload desk, migration assistant, review table, minimal prompt, spreadsheet, recovery board, source catalog, timeline, comparison matrix, URL lab, inventory dashboard, mobile, modal, and inline current-import card.
- Product constraints represented: GitHub repo/directory, WordPress REST/WXR, feeds/OPML, reachable URLs, server paths, uploads/folders/archives, URL treatment ask/preserve/rewrite, old domains, drafts, dry run, import stages, URL decisions, media, comments, abort, and completion.
- Unsupported connector claims such as Shopify, Notion, Drive, Slack, account auth, arbitrary DB tables, and custom post type imports are intentionally excluded.
