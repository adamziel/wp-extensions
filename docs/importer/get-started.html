Start an import session

Use PortPress in Playground for a quick browser test, or install the current import plugin in WordPress when you need real storage, larger files, or repeatable WP-CLI runs.

1. Try the Playground demo

The demo opens a PortPress guide with the importer, exporter, and sample source folder already set up. Paste the bundled source path below, then run a dry run before creating drafts.

/wordpress/wp-content/uploads/portpress-source

2. Install in WordPress

cp -R universal-wordpress-importer /path/to/wordpress/wp-content/plugins/

Activate Universal WordPress Importer, open Tools -> Universal Importer, choose the source type, and start with a dry run when you want to inspect what will be created. This is the current implementation name for the import workflow.

3. Run imports from WP-CLI

CLI runs use the same durable tables as the admin UI, so a session can pause for a decision and resume later.

wp plugin activate universal-wordpress-importer
wp universal-importer import ./content-export.zip
wp universal-importer status import_...
wp universal-importer tick import_...

4. Decide URL treatment deliberately

When imported content contains absolute links to the old site, the importer asks whether those hosts should move to this WordPress site. Confirm only first-party domains; social networks and external references should usually stay unchanged.

wp universal-importer decide import_... confirm-first-party-domains \
  --confirmed-domains=example.com,www.example.com

5. Review drafts

The importer writes draft pages so you can inspect titles, hierarchy, media, stripped scripts, rewritten links, and block conversion before publishing anything.
