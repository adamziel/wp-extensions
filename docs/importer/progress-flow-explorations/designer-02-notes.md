# Designer 02 Notes

1. [Validation Inbox](designer-02-journey-06.html) - An inbox-style triage surface for warnings, missing media, duplicate slugs, and blockers.
2. [Import Kanban](designer-02-journey-07.html) - Record readiness is managed across Ready, Needs Mapping, Warnings, Failed, and Imported lanes.
3. [Schema Blueprint Builder](designer-02-journey-08.html) - A structural canvas for post types, taxonomies, authors, media, and custom fields.
4. [Step Wizard With Live Rail](designer-02-journey-09.html) - A guided setup flow with persistent live summary, counts, mappings, and risks.
5. [Diff Review Interface](designer-02-journey-10.html) - A Git-style comparison view for accepting, rejecting, or overriding incoming changes.
