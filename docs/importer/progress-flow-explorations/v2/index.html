Import content into WordPress. Start with a source, review what will be created or updated, then run the import with checkpoints and rollback details.

Tools > Universal Importer

What do you want to import?

Paste a URL, choose an export file, or drop a source archive. The importer will inspect the source before anything is written to the site.

Supported sources include WordPress XML, CSV, JSON, ZIP archives, Markdown, HTML, RSS, and Atom feeds.
