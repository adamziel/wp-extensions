# Designer 01 Notes

1. [Guided Source Start](designer-01-journey-01.html) - Source, mode, and safety choices stay visible until the user starts.
2. [Fast Paste With Preview](designer-01-journey-02.html) - A pasted URL is recognized immediately and converted into a precise import summary.
3. [GitHub Path Discovery](designer-01-journey-03.html) - The first seconds name the repository operation instead of showing a dead queue.
4. [Dry Run First](designer-01-journey-04.html) - Unfamiliar sources can be checked first without leaving the main flow.
5. [Browser Folder Import](designer-01-journey-05.html) - Upload progress and server-side import progress are separate, visible phases.
