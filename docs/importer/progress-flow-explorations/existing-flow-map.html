Key Confusing Points

  • Source shortcuts mostly change placeholders; Browser folder is the only immediate picker action.
  • Browser uploads silently override the typed source flow and omit source from upload submit.
  • Keepalive runs real importer work, not just status polling.
  • Current GitHub import code has sparse-Git-only behavior while some docs still mention tree/blob or zipball fallback.
  • Dry run can still pause for URL treatment.
  • The admin default publishes pages unless Import as drafts is checked, while docs often frame imports as draft/review flows.
  • Generic relationship decisions require hand-edited JSON after the page already exists.
  • Any decision resolution currently shows "URL choice saved.", even for non-URL decisions.
  • Abort is not rollback.
  • View imported content appears only for completed sessions with persisted page records.
