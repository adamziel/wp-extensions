# Designer 04 Notes

1. [One-screen Impatient](designer-04-journey-16.html) - The fastest path keeps source, mode, progress, and review in one dense surface.
2. [Minimal Choices](designer-04-journey-17.html) - Advanced controls are visible as compact toggles, not another setup screen.
3. [Review-first Done](designer-04-journey-18.html) - Completion leads directly to imported drafts and session evidence.
4. [Problem State Recovery](designer-04-journey-19.html) - Failures show the failed candidate, the next automatic attempt, and manual actions.
5. [Dashboard Queue](designer-04-journey-20.html) - Multiple sessions can be scanned by status, phase, and required action.
