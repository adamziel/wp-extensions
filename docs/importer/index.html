Import workflow

Turn source material into reviewable WordPress drafts.

PortPress imports folders, archives, documents, feeds, repositories, WXR exports, PDFs, and public sites through durable sessions that can pause, resume, import media, and ask for URL decisions when guessing would be risky.

See supported formats
1. Select sourceUpload files, enter a path, paste a URL, or use a feed.
2. Prepare contentDetect formats, convert blocks, and queue media references.
3. Resolve decisionsConfirm first-party domains and relationship mapping when needed.
4. Review draftsInspect pages before anything becomes public.

Designed for imperfect sources

The importer favors predictable drafts over false fidelity. When a source cannot map cleanly to native blocks, it preserves safe content instead of inventing structure.

Start with a dry run when you need to understand a source tree before creating pages.

Content trees

Local folders, browser uploads, dropped folders, ZIP archives, nested archives, Markdown, HTML, text, and EPUB files.

Site sources

Public WordPress REST sites, ordinary site URLs with advertised feeds, direct RSS/Atom/RDF feeds, and single HTML pages.

Exports

WXR files, post entities, terms, comments, relationship decisions, and media references from local or confirmed first-party sources.

PDFs

Native first-pass text and image extraction with optional command templates for layout-aware text extraction or OCR.
