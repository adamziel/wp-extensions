Formats

The importer favors predictable drafts over false fidelity. When a format cannot be mapped cleanly to native blocks, it preserves safe HTML in Classic or Custom HTML blocks rather than inventing structure.

Documents

SourceResultNotes
MarkdownHeadings, paragraphs, lists, quotes, tables, and linksNested trees become separate draft pages.
HTMLNative blocks where safe, Classic or Custom HTML otherwiseScripts and unsafe attributes are stripped.
TextParagraph blocksUseful for notes and plain exports.
EPUBOne prepared document per spine itemCross-document link checks run across the full prepared set.
PDFText blocks and embedded images where recoverableOptional helpers improve text order and OCR for hard PDFs.

Sites and Feeds

SourceResultNotes

WordPress homepageREST import when discoverableFalls back to an advertised feed or the single page.
RSS, Atom, RDFOne draft per feed itemImports current feed items, not historical feed archives.
GitHub repository URLRepository tree contentGood for docs, Markdown sites, and public content repositories.
WXRWordPress export entitiesMay pause for author, term, relationship, or URL decisions.

PDF Helpers

Native PDF extraction is bounded and works best on straightforward text PDFs. For layout-heavy or scanned documents, configure command templates on the host:

export UNIVERSAL_IMPORTER_PDF_TEXT_COMMAND='pdftotext -layout {input} {output}'
export UNIVERSAL_IMPORTER_PDF_OCR_COMMAND='ocrmypdf --skip-text --sidecar {output} {input} {scratch}'
