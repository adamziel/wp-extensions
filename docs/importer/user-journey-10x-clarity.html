Source type

Accepts URLs, repositories, feeds, server paths, uploads, WordPress exports, and documents.

First run is always a dry run. WordPress scans this source and writes no content until you review the result and choose the real import.

What each source supports
GitHub Repositories, branches, folders, files, releases, Markdown docs, and linked assets.
WordPress site Posts, pages, media, authors, comments, REST API content, and WXR exports.
Feed or OPML RSS, Atom, JSON Feed, podcast feeds, and grouped feed lists.
Server path Mounted folders, ZIP/archive paths, local export directories, absolute paths, and import staging areas.
Browser upload Files selected from this device when the source is not reachable from the server.
Archive or document ZIP, WXR, Markdown, HTML, PDF, EPUB, XML, SQL, OPML, and plain text files.
