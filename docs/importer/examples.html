Examples

These examples are deliberately small enough to verify quickly and realistic enough to exercise the importer pipeline.

Bundled Playground Source

Open the demo, paste this path, and run a dry run before creating drafts:

/wordpress/wp-content/plugins/universal-wordpress-importer/examples/playground-import

The sample includes Markdown, HTML with a stripped script, plain text, and a nested appendix.

RSS or Atom Feed

Paste a public feed URL into the source field. The importer creates one draft per current feed item and resolves relative feed media against the item URL.

https://wordpress.org/news/feed/

WordPress Site URL

Paste a homepage or REST root. The importer tries the WordPress REST API first, then an advertised RSS or Atom feed, then the single page.

https://example.com/
https://example.com/wp-json/

GitHub Repository

Use a public repository URL when the content already lives in GitHub.

https://github.com/example/docs/tree/main/content

Host CLI Smoke Test

Run a focused import from the repository checkout:

wp universal-importer import ./universal-wordpress-importer/examples/playground-import
wp universal-importer status import_...
