WordPress to portable static HTML

StillPress exports WordPress sites into files you can preview, inspect, zip, and host anywhere.

Run it in browser Playground, Playground CLI, regular WordPress admin, or WP-CLI. It crawls public pages, rewrites same-site URLs, copies frontend assets, and keeps the export portable by default.

What It Exports

Pages That Stay Pages

Each discovered URL is rendered and written to its own static path, including linked posts, pages, categories, authors, and finite query pages.

Portable Links

Relative URLs are the default, so exports work from a ZIP preview, subfolder, GitHub Pages, or a local HTTP server.

Frontend Assets

The exporter copies uploads, active theme assets, active plugin assets, WordPress frontend assets, and same-site assets discovered in HTML and copied text files.

CLI and Admin

Use the WordPress admin screen for one-click ZIP downloads or `wp static-site export` for repeatable command-line builds.

Demo Sites

Start with the seeded StillPress demo for a compact content site, or open the BrewCommerce demo to test WooCommerce pages, products, cart snapshots, images, and product grid CSS.
