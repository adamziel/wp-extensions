Agent Review Checklist

Composition

  • Three stages align to one grid and one baseline.
  • The center stage does not overpower the source and output stages.
  • No label depends on tiny text to explain the workflow.

Motion

  • Every frozen frame looks intentional, not like a glitch.
  • Only one idea moves at a time per direction.
  • Reduced-motion keeps a useful static diagram.

Responsive

  • The diagram remains understandable at 390px wide.
  • SVG text remains readable or becomes decorative only.
  • The caption supports the figure instead of competing with it.

Production

  • The same SVG is used here and on the landing page.
  • The SVG parses with `xmllint`.
  • The docs test covers required labels and reduced-motion CSS.
