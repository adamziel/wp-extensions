Get Started

StillPress works in four environments: browser Playground, Playground CLI, regular WordPress admin, and regular WordPress WP-CLI.

Browser Playground

Open the demo Blueprint, then use Tools -> StillPress to download the ZIP.

Playground CLI

mkdir -p ./static-site-output
npx @wp-playground/cli@latest run-blueprint \
	--mount=./static-site-generator:/wordpress/wp-content/plugins/static-site-generator \
	--mount=./static-site-output:/exports \
	--blueprint=./blueprints/static-site-generator-cli-export.json

The generated ZIP is written to ./static-site-output/static-site.zip.

Regular WordPress Admin

cp -R static-site-generator /path/to/wordpress/wp-content/plugins/

Activate StillPress, then open Tools -> StillPress. The default portable link mode is the right choice for ZIP previews, subfolders, and GitHub Pages.

Regular WordPress WP-CLI

wp plugin activate static-site-generator
wp static-site export --output=./static-site.zip --fetch-mode=auto
wp static-site export --output-dir=./static-site --fetch-mode=auto

Useful flags include --url-mode=relative, --url-mode=root, --url-mode=absolute, --fetch-mode=internal, --generate-sitemap, --generate-robots, and --report.

Preview The Export

After extracting the ZIP, run a local HTTP server from the extracted folder:

python3 -m http.server 8080

Then open http://localhost:8080/. Direct file:// previews are useful for quick HTML and CSS checks, but local HTTP is the closer match for production hosting.
